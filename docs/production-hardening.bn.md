# সম্মুখভাগের অতিরিক্ত উৎপাদন-প্রস্তুতির যাচাই

তারিখ: ৯ অক্টোবর ২০২৬।

bKash ব্যবহারকারীর অনুরোধে স্থগিত। এই ধাপে কোনো bKash পরীক্ষা চালানো হয়নি। স্থানীয় নতুন কোড কমিট, পুশ বা প্রকাশ করা হয়নি।

- ধরন যাচাই ও উৎপাদন বিল্ড সফল।
- ৩৮টি ব্রাউজার পরীক্ষা সফল; উৎপাদন বিল্ডে Edge ব্যবহার হয়েছে। অধিকাংশ API উত্তর নিয়ন্ত্রিত নকল।
- নির্ভরতার সব পরীক্ষায় পরিচিত দুর্বলতা শূন্য; CI-তে উচ্চ/গুরুতর দুর্বলতার পরীক্ষা যোগ হয়েছে।
- লিন্টে ত্রুটি নেই; পুরোনো sidebar পছন্দের কুকিতে একটি সতর্কতা আছে।
- ফ্রেম, অবজেক্ট ও base URL-এর সীমিত নিরাপত্তা নীতি যোগ হয়েছে; পূর্ণ script nonce নীতি নয়।
- ব্যবহারকারীর পূরণ করা কোম্পানির পরিচয় আইনি পরিচিতি ও যোগাযোগের পাতায় মিলেছে। যোগাযোগের ইমেইল/ফোনের লিংক, বাংলা লেখা ও পুরোনো অসম্পূর্ণ তথ্যের বার্তা সংশোধিত।
- আইনি পাতাগুলো এখনো খসড়া; ব্যবসায়িক/আইনি নীতির কিছু প্লেসহোল্ডার বাকি।
- পূর্ণ-পথসহ বর্তমান কোডের নথিতে ১২৯টি ফাইল আছে।

প্রকাশ্য সম্মুখভাগের API proxy ব্যবহার করে বাস্তব ছবি আপলোড, ডেটাবেসে সংরক্ষণ, প্রোফাইল পড়া ও প্রদানকারীর ডাউনলোড সফল; নিজের পরীক্ষার ছবি এবং সেশন পরিষ্কার হয়েছে। ব্রাউজারের ফাইল বাছাই পরীক্ষা নয়।

সম্পূর্ণ ফল, পশ্চাৎভাগের ৩৪টি ইউনিট ও আটটি সমন্বিত পরীক্ষার ফল, Stripe পুনরাবৃত্তির সীমা, ব্যাকআপ মহড়া এবং প্রকাশের আগে অবশিষ্ট শর্ত: [সমন্বিত প্রতিবেদন](D:/NEXT_LEVEL_WEB_DEV/assignment/courier-backend/docs/production-hardening.bn.md)।

নতুন স্থানীয় CI বিধি GitHub runner-এ চলা, বাস্তব অ্যাকাউন্টের সম্পূর্ণ গ্রহণযোগ্যতা পরীক্ষা, উৎপাদনের চাপপরীক্ষা/ব্যাকআপ/সতর্কতা এবং প্রকাশ-পরবর্তী smoke test এখনো বাকি। পুরো অ্যাপকে নিঃশর্ত উৎপাদন-প্রস্তুত বলা হচ্ছে না।
